识膳智行 · 移动端五大模块

由原 9 个功能页重构为 5 个模块，按「定计划 → 执行 → 记录 → 反馈 → 激励」闭环组织　|　新增 标记为本次新做的能力

模块 定位 包含内容 来源
计划 定目标的入口，把偏好变成可执行的每日方案
  1. 生成计划：勾选口味偏好与饮食禁忌 → 本地模型抽取约束 → 约束求解器逐天生成、流式展示
  2. 展示计划：逐天查看、可视化编辑、一键导入日历
  3. 食物热量识别快捷键新增
 原「养生方案」整体升级为一级模块；快捷键为本次新增
日程 每天的执行层，方案在这里落地成待办
  1. 每日打卡：餐食（早 / 午 / 晚 / 加餐）、运动（按计划下发）、睡眠（按计划下发）新增、饮水新增
  2. 食物打卡 + 饮水打卡合成一个独立模块，拍照识别热量成为该模块内的一个功能新增
  3. 页面顶部健康三环进度卡片新增（只展示当天）
 原「健康打卡」升级为执行层；原「食物识别」由一级页面降为模块内功能
运动 运动记录的独立主场，产出运动三环
  1. 多项目实时记录：跑步、竞走、跳绳等，按项目类型 + 时长 + 强度记录新增
  2. 自动算消耗：复用已有 MET 代谢当量模型，写回当天日程
  3. 运动三环（步数 / 运动时长 / 消耗）的数据来源新增
 原运动打卡的 MET 消耗模型复用；项目体系与实时记录界面为本次新增
社区 内容与社交，同时是激励体系的入口
  1. 动态分享：发布饮食 / 运动记录与心得，浏览、点赞、分享新增
  2. 排行榜小板块：Redis ZSet 实时排名 + 头衔徽章（Redis 不可用时自动降级 SQLite）
  3. 奖励小板块：积分商城，权益券 / 实物券 / 核销码 / 库存扣减，成就徽章并入
 动态流为本次新增；排行榜、积分商城、成就徽章由原一级页面迁入
我的 所有数据的收口与可视化监控中心
  1. 快捷入口：健康档案、体重记录、积分流水、商城订单、成就徽章
  2. 手环设备接入：小米 / 华为 / Apple 健康等品牌数据导入，与站内识别、打卡、运动、睡眠记录合并去重新增
  3. 健康三环 + 运动三环：睡眠 / 饮食 / 运动，以及步数 / 时长 / 消耗新增
  4. 可视化图表：折线图（热量、体重趋势）、柱状图（近 30 天热量）、环形百分比图（营养结构）
 原「仪表盘 / 健康档案 / 数据追踪 / 成就徽章」四页收束；手环（另一分支）与三环、图表为新增
说明：手环功能归属「我的」，不单独占一级入口；其数据参与全局三环计算，三环在「日程」页顶部显示当日进度，完整三环与所有图表统一在「我的」查看。
