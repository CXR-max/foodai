# 2026-11-17

## 地图方案升级：Canvas 自绘 → Leaflet + 高德瓦片
- `TrackMap.vue` 重写为 Leaflet 版：真地图、可拖拽、双指缩放、双击放大
- 底图仍是高德瓦片（免 key、免备案），坐标转换 WGS-84→GCJ-02 保留
- 瓦片连续失败且零成功时 `offline=true`，容器 CSS 网格兜底，轨迹照常画
- 接口保持不变（points/live/height），RunTrackView 与 WorkoutDetailView 无需改
- 依赖新增：leaflet + @types/leaflet（生产包 gzip 45KB）

## 首屏减重（手机打不开的另一半原因）
- `LoginView.vue`、`ProfileView.vue` 中的 `FaceCaptureDialog` 由静态 import 改为 `defineAsyncComponent`
- 原因：该组件静态依赖 `@mediapipe/tasks-vision`（node_modules 20MB，public/mediapipe 19MB WASM），
  静态引入会把登录页首屏拖死；现在只在点「人脸登录/绑定人脸」时才加载

## 手机访问链路
- `vite.config.ts` 新增 `preview` 配置：port 4173、host 0.0.0.0、allowedHosts、/api 与 /uploads 代理
- 生产构建后首屏约 300KB gzip（dev 模式 2~3MB），局域网秒开
- 启动：`npm run preview -- --host ::`（双栈，同时监听 IPv4/IPv6）
- 实测失败方案：localhost.run（限速 2~3KB/s）、pinggy 免费版（插入警告页 + 2.3KB/s）→ 隧道不可用
- 可行路径：局域网 `http://172.20.10.7:4173`；公网走 IPv6 `http://[2409:...]:4173`（IPv6 为临时地址会变）
- 二维码脚本：`frontend/scripts/qr.cjs`，输出 docs/screenshots/qr-lan.png、qr-wan.png
- 截图校验脚本：`frontend/scripts/verify.cjs`（统计高德瓦片 200 数量，确认底图真的加载）
